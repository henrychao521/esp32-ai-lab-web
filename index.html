ESP32 AI Lab 首燒

只做一次：把 MicroPython 與代理程式裝進板子，之後學生全用 Wi-Fi。需要桌機 Chrome 或 Edge（iPad／Safari 不支援 Web Serial）。

這個瀏覽器沒有 Web Serial。請改用電腦上的 Chrome 或 Edge 開這一頁。

1燒入 MicroPython 韌體

先讓板子進下載模式，再按安裝（T-QT Pro 這類原生 USB 的板子一定要做）：
  1. 按住 BOOT 鍵（T-QT Pro 是左邊那顆按鍵）不放。
  2. 按一下 RST（沒有 RST 鍵就拔掉 USB 再插回去）。
  3. 放開 BOOT。螢幕會是黑的，這是正常的。
  4. 按下面「安裝 MicroPython」，在跳出的視窗重新選一次序列埠（名稱可能變了，通常含 usbmodem、ESP32-S3、SLAB 或 wchusb）。

為什麼：板子跑 MicroPython 或 Arduino 程式時，USB 由程式自己接管，瀏覽器的自動重置訊號（DTR／RTS）到不了晶片，會出現「Installation failed: Failed to initialize」。手動按 BOOT＋RST 讓 ROM 接管 USB 就能燒。整顆抹除後重燒約 20 秒。

燒錄失敗（Failed to initialize）＝板子還沒進下載模式。 照上面四步：按住 BOOT → 按 RST（或重插 USB）→ 放開 BOOT → 再按「安裝 MicroPython」並重新選序列埠。 若還是失敗，換一條有資料線的 USB 線、不要經過集線器。

2安裝代理程式並設定 Wi-Fi

再選一次序列埠（韌體燒完板子會重新連線）。代理程式會寫進板子，之後開機自動連 Wi-Fi、開 HTTP／WebSocket 服務。

留空 Wi-Fi：板子開機會開熱點 ESP32LAB-xxxx（密碼 esp32lab），手機連上後開 http://192.168.4.1 填。








3完成：打開板子上的網頁版 IDE


板子重開後，螢幕（或序列埠）會顯示名稱 esp32lab-xxxx.local 與 IP。之後都不必再接 USB：
同一個 Wi-Fi 的 iPad／手機／電腦用瀏覽器打開板子，就能寫程式、貼上 AI 的程式、看主控台、遙控。


打開 http://esp32lab-xxxx.local


網址在步驟 2 完成後會自動填上；也可以手動輸入 http://esp32lab-xxxx.local（mDNS 不通時改用 IP）。驗證：/info 應回傳 JSON；/screen.bmp 是目前畫面。
教室伺服器（老師電腦）的 http://老師IP:8765 提供同一份 IDE 當備援，並有老師頁可一鍵更新全班板子。
